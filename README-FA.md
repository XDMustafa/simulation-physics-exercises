# تمرین‌های شبیه‌سازی و فیزیک محاسباتی

مجموعه‌ای از تمرین‌های محاسبات عددی و فیزیک محاسباتی، شامل مباحث شبیه‌سازی، روش‌های عددی و فیزیک محاسباتی — همگی پیاده‌سازی‌شده با پایتون.

## درباره پروژه

این مخزن شامل حل و بررسی مسائلی از حوزه فیزیک محاسباتی و عددی است. تمرین‌ها از مسائل کتاب‌های مرجع — از جمله *Mathematical Methods using Python: Applications in Physics and Engineering* — تا ایده‌های کوچک‌تر و مستقلی که در حین کار با این مطالب شکل می‌گیرند را شامل می‌شود.

تمامی پیاده‌سازی‌ها با زبان پایتون و در قالب Jupyter Notebook تهیه شده‌اند.
